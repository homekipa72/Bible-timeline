# 말씀의 길 (Malssumgil)

한국천주교주교회의 공식 성경 본문을 연동한 **가톨릭 성경 통독** 웹앱입니다. 홈 화면에 추가하면 앱처럼 설치해 쓸 수 있습니다(PWA).

## 주요 기능

- **장·절 읽음 기록** — 절을 눌러 표시, 장 단위 완료 처리. 시편은 **편**으로 표기
- **통독 계획 (최대 5개)** — 범위: 전체통독 · 연대기별(12시대) · 개별 선택(구약·신약·복음서·시편 빠른 선택 포함). 기간: 총 일수 · 하루 분량 · 종료일, 주일 제외 옵션
- **밀린 분량 처리** — 지난 일정 중 못 읽은 장을 홈 카드에 알려 줍니다. *밀린 분량 읽기 · 건너뛰기(되돌리기 가능) · 남은 기간에 다시 배분* 중에서 고를 수 있고, 계획별로 "밀리면 자동 재배분" 방식을 켤 수 있습니다
- **구절 복사** — 성경 읽기 화면에서 *구절 복사* 모드로 절을 골라 "창세기 1,1-3.5" 같은 출처와 함께 복사(절 번호 포함 여부 선택, 각주 번호 제외)
- **오늘의 한 줄** — 홈에서 바로 한 줄 기록(구절은 마지막 읽은 장으로 자동 입력), 연속 기록 일수 표시
- **묵상 노트** — 수정 · 검색 · 정렬(최신/수정일/오래된순) · 한 줄/묵상 필터, 날짜별 묶음
- **말씀 알림** — 통독 계획의 날짜별 분량을 캘린더 파일(.ics)로 내보내 정해진 시각에 알림 (아래 참고)
- **공유 카드** — 말씀 카드(선택한 절) · 묵상 카드 · 진도 카드를 이미지로 저장·공유 (남색/아이보리/초록)
- **읽기 설정** — 글꼴, 글자 크기(14~32px), 줄 간격(4단계), 각주 번호 숨기기
- **오프라인** — 본문은 장 단위로 IndexedDB에 저장, 앱 화면은 서비스 워커가 캐시
- **진도 시각화** — Chart.js 차트, Web Worker 비동기 집계
- **백업·기기 이동** — JSON 파일 또는 동기화 코드

본문 출처: [한국천주교주교회의 성경](https://bible.cbck.or.kr/Knb)

## 저장소 구조

```
malssumgil-c-mode/
├── index.html              # 프론트엔드 (SPA, CSS·JS 포함)
├── sw.js                   # 서비스 워커 (오프라인 앱 화면 캐시)
├── manifest.webmanifest    # PWA 설치 정보
├── icons/                  # 앱 아이콘 (svg, 192/512/maskable, apple-touch)
├── api/
│   └── bible.js            # Vercel Serverless — 성경 HTML 프록시
├── server.js               # Node 실행 시 정적 앱과 성경 API 제공
├── Dockerfile              # Node 서버 기반 컨테이너 배포
├── manus-routes.json       # 미리보기 페이지 경로
├── package.json
├── vercel.json
├── README.md
└── .gitignore
```

> `bible.js`는 반드시 `api/` 폴더 안에 있어야 `/api/bible`로 동작합니다.

## Vercel 배포

### 방법 A — 대시보드 (추천)

1. [vercel.com](https://vercel.com) 로그인
2. **Add New Project** → GitHub 저장소 연결
3. Framework Preset: **Other** (또는 기본값 유지)
4. Root Directory: 저장소 루트
5. **Deploy**

```bash
npm i -g vercel
vercel login
vercel        # 미리보기
vercel --prod # 프로덕션
```

## 로컬 실행

API(`/api/bible`)가 필요하므로 `index.html`만 열면 본문 불러오기가 동작하지 않습니다.

Node.js 18 이상에서는 별도 패키지 설치 없이 실행할 수 있습니다.

```bash
npm start
```

브라우저에서 `http://localhost:3000` 접속. (서비스 워커는 `localhost`와 `https`에서만 동작합니다.)
Vercel CLI 환경을 사용하려면 기존과 같이 `vercel dev` 또는 `npm run dev:vercel`을 실행할 수 있습니다.

## 앱처럼 설치하기 (PWA)

- **아이폰·아이패드**: Safari에서 열기 → 공유 버튼 → **홈 화면에 추가**
- **안드로이드·크롬**: 주소창의 설치 아이콘 또는 메뉴 → **앱 설치**
- 처음 한 번 인터넷에 연결해 열어 두면 이후 앱 화면은 오프라인에서도 열립니다. 성경 본문은 **한 번 읽은 장**(또는 성경 읽기 화면의 미리받기 버튼으로 받아 둔 책)만 오프라인에서 볼 수 있습니다.

### 앱 파일을 수정한 뒤 배포할 때

`sw.js` 맨 위의 `CACHE_VERSION`(`'v1'` → `'v2'` …)을 올리면 이전 캐시가 정리되고 새 파일이 반영됩니다. 올리지 않아도 화면 이동 시 네트워크 우선으로 가져오지만, 아이콘·정적 파일은 한 번 더 열어야 갱신될 수 있습니다.

## 말씀 알림 (캘린더)

**통독 계획** 탭의 *말씀 알림* 카드에서 계획·알림 시각·미리 알림·범위를 고르고 *캘린더 파일 만들기*를 누릅니다. 모바일에서는 공유 시트가, 컴퓨터에서는 파일 다운로드가 열립니다. 파일을 열어 캘린더에 추가하면 매일 "말씀의 길 · 창세기 1–3장" 같은 알림이 울립니다.

- 앱 자체의 푸시 알림이 아니라 기기 캘린더의 알림을 이용합니다(서버가 필요 없음).
- 일정은 계획의 **원래 날짜 기준**입니다. 자동 재배분 방식으로 바꾼 계획도 알림은 원래 일정으로 만들어집니다.
- 같은 계획으로 다시 만들어 추가하면 대부분의 캘린더 앱에서 같은 날짜의 일정이 갱신됩니다.

## 데이터 보관과 백업

진도·노트·계획은 **브라우저 로컬 저장소**에만 보관됩니다. 계정 로그인이나 서버 동기화는 없습니다. 기기를 바꾸거나 브라우저 데이터를 지우기 전에는 **통독 기록 탭**에서 백업하세요.

저장소는 안전 래퍼(`store`)를 거칩니다. 사생활 보호 모드나 저장 공간 부족으로 저장이 막히면 앱은 멈추지 않고 그 화면에서만 임시로 기록하며, 안내 메시지를 한 번 띄웁니다. 저장된 값이 손상되어 읽을 수 없으면 기본값으로 시작하고, 손상된 원본은 `<키>__corrupt`로 따로 남겨 복구할 수 있게 합니다.
웹 주소나 브라우저가 바뀌면 저장소가 분리되므로 이전 주소에서 JSON을 내보내고 새 주소에서 가져와야 합니다. JSON 백업에는 오프라인 성경 본문이 포함되지 않으므로 새 주소에서 필요한 장을 다시 불러오거나 내려받아야 합니다.

| 방법 | 설명 |
|------|------|
| JSON 내보내기 / 가져오기 | 파일로 저장해 다른 기기에서 불러오기 |
| 동기화 코드 | 코드를 복사해 다른 기기에 붙여 넣기 (계정 없이 수동 이동) |

백업(v2)에 포함되는 항목: 읽은 절·장 기록, 묵상 노트(수정·검색용 정보 포함), **저장된 통독 계획 5개**(건너뛴 분량·재배분 설정 포함), 활성 계획, 계획별 마지막 읽은 위치, 읽기 설정(글꼴·크기·줄 간격), 각주 숨김. 이전 버전(v1) 백업 파일도 가져올 수 있으며, 이 경우 계획·읽기 설정은 현재 기기의 값을 그대로 둡니다.

## API

`GET /api/bible?book={코드}&chapter={장}`

| 파라미터 | 예 | 설명 |
|----------|-----|------|
| book | `Gn`, `Ps`, `Mt` | CBCK 책 코드 |
| chapter | `1` | 장(시편은 편) 번호 |

응답: 해당 장 HTML (CDN 캐시 헤더 포함). 서비스 워커는 이 경로를 가로채지 않으며, 앱이 받은 본문을 IndexedDB에 직접 저장합니다.

## 참고

- 본문은 공식 사이트에서 **장 단위로 가져와** 기기에 저장합니다. 73권 일괄 탑재는 하지 않습니다.
- 운영 시 CBCK 이용 약관·승인 범위를 확인하세요.
